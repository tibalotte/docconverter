Ouvrir le dossier data d'une voiture

Choisissez le dossier content/cars/<voiture>/data (déjà dépaqueté). Les fichiers tyres.ini, suspensions.ini et setup.ini y seront lus, modifiés et enregistrés sur place, après une sauvegarde automatique dans .acmod_backup/.

Mode de repli (Firefox, Safari, ou sans accès en écriture)

Importez le dossier data (ou un zip qui le contient). Rien n'est envoyé sur internet : les modifications restent dans la page, puis vous téléchargez les fichiers modifiés pour les recopier vous-même dans le dossier de la voiture.

Attention : une voiture modifiée ne passe plus les vérifications de fichiers des serveurs en ligne. Gardez ces modifications pour le jeu hors ligne, et respectez la licence du contenu que vous modifiez.
